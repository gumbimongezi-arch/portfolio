# Frankenstein Sibanyoni — Portfolio

A self-contained, responsive portfolio site of Frankenstein Sibanyoni.

## Run locally

Open `index.html` in any modern web browser. No installation, framework, server, or build command is required.

## Structure

- `index.html` — page content and accessibility structure
- `styles.css` — responsive visual design
- `script.js` — navigation and in-page document viewers
- `assets/` — profile photo, certificates, course files, CV, and project documentation

The portfolio intentionally presents credentials and documents in view-only modal viewers. It does not provide download buttons.
